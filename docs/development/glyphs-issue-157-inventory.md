## Library-Generated Alert Icons

The #139 change added an `alert_icon` override returning `!` for every kind;
the removed lines do not enumerate the prior symbols. In `tui-markdown`
0.3.12 (`Cargo.lock`), `StyleSheet::alert_icon` previously supplied these
original strings: NOTE `\u{2139}\u{fe0f}`, TIP `\u{1f4a1}`, IMPORTANT
`\u{2757}`, WARNING `\u{26a0}\u{fe0f}`, and CAUTION `\u{1f534}`. These are
generated markers, not content from the Markdown author. They have their own
rendered widths, which must be counted; the middle-dot measurement does not
make emoji one column wide. The 2-column and unknown-policy fallback is `!`.
