# 開発状況

更新: 2026-10-26。Shellboyへの改名と公開用構成の準備中です。まだpushしていません。

## 実装の範囲

TUI、同一ownerへ接続するCLI、Responses互換通信、shell、親子の会話と実行、待機、分岐履歴、要約・スピル、添付、埋め込み索引、GC、同梱ガイド、独立RAGの実装があります。責務と対象外は [適用仕様](../design/effective-spec.md) に記載します。コードや文書が存在することを、全環境での受入完了とは扱いません。

改名前には不具合是正と構造整理を実施しています。その作業記録は旧リポジトリに保管し、公開版の新しいGit履歴と区別します。過去の件数・commit・実API・画面記録はShellboy版の合格根拠として転載しません。

## 今回の境界と次の確認

- package、実行名、環境変数、既定保存先をShellboyへ統一する。旧名の互換経路は提供しない。
- 旧データの移動は不要。新しい既定保存先を使い、利用者の既存設定・DBを変更しない。
- 公開版は同梱ガイド・採用設計・配布migrationだけで開発できる構成にする。
- 改名後のビルド・標準チェック・オフラインdocs・一時data-dirでの起動終了・公開用初期cloneの参照確認は、結果が揃ってから [検証状況](../validation/acceptance.md) を更新する。現時点では完了を宣言しない。
- 実機や操作環境がないOS・端末・IMEは未実施とし、その確認待ちで利用可能な環境の作業を止めない。

公開用ディレクトリには新しいGit履歴を作り、旧リポジトリの履歴は保管します。リモートへのpushはまだ行いません。
